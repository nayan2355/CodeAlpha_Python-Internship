###  Tasks Completed

#### **Task 1: Hangman Game**
A classic word-guessing game in the console.
- Random word selection from a list
- Tracks remaining tries and guessed letters
- **Run:** `python Task-1_Hangman-Game/hangman.py`

#### **Task 2: Stock Portfolio Tracker**
Tracks stock investments and calculates total value.
- Hardcoded stock prices (AAPL, TSLA, GOOGL, MSFT)
- User input for quantity
- Saves portfolio to `portfolio.txt`
- **Run:** `python Task-2_Stock-Tracker/stock_tracker.py`

#### **Task 3: Task Automation with Python Scripts**
Automates 3 real-life tasks:
1.  Moves all `.jpg` files from `source_folder` to `jpg_folder`
2.  Extracts emails from `sample.txt` using Regex
3.  Scrapes website title from python.org
- **Run:** `pip install -r Task-3_Task-Automation/requirements.txt` then `python Task-3_Task-Automation/automation.py`

#### **Task 4: Basic Chatbot**
A simple rule-based chatbot that responds to greetings.
- Responds to hi, hello, how are you, name, bye
- **Run:** `python Task-4_Basic-Chatbot/chatbot.py`
